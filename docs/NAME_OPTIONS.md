# Model and Tool Name Options

Possible names for the model/tool family:

| Name | Rationale |
| --- | --- |
| IZ-Scout | Short, practical, suggests genome-wide candidate discovery. |
| OriZone | Connects replication origins with initiation zones. |
| IZMap | Clear and direct for a genome-wide mapping tool. |
| OriginLens | Emphasizes model-based inspection and interpretability. |
| RepOri-Scout | More explicit replication-origin framing. |
| KAIROS-IZ | Memorable, but less self-explanatory; useful if a branded model name is wanted. |
| OriFinder-IZ | Direct but may be confused with existing Ori-Finder tools. |
| IZ-Atlas | Good if the project will expand to multiple cell types and genomes. |
| OriginFormer-IZ | Highlights the transformer model, but may overstate architecture branding. |
| OriSignal | Emphasizes continuous genome signal tracks and bedGraph output. |

Working package name in this repository: `iz-origin-scanner`; CLI command: `izscan`.
